# PLATEAU 交通空白地可視化・施策シミュレーション（呉市 宮原地区 / 広島市安佐南区 毘沙門台エリア）

CesiumJS で PLATEAU の建物3D Tiles（LOD1）・地形を表示し、急傾斜市街地である「呉市（宮原地区）」および「広島市安佐南区（毘沙門台）」の交通空白地可視化および施策シミュレーションを行うWebアプリケーションです。画面左上のセレクターから両エリアを切り替えて検証できます。

## 対象エリア設定

### 1. 呉市（宮原地区）※デフォルト
- **対象地域**: 広島県呉市宮原1丁目〜8丁目周辺（急傾斜市街地、自治体コード: `34202`）
- **中心座標**: 北緯 `34.2435` 度、東経 `132.5630` 度
- **初期カメラ位置**: 呉港・二河川河口側から呉駅・宮原・和庄・内陸斜面市街地を見通す俯瞰アングル（高度約 `2350m`、`heading: 42°`、`pitch: -23°`）
- **周辺メッシュコード**: `51322485`、`51322486`、`51322475`、`51322476`
- **交通施設**: JR呉線（呉駅、川原石駅、安芸阿賀駅）、広電バス・呉市生活バス等の停留所網（398箇所）
- **勾配負荷パラメータ**: 急傾斜市街地・階段補正（上り坂換算倍率 一般1.55倍 / 高齢者1.85倍）

### 2. 広島市安佐南区（毘沙門台エリア）
- **対象地域**: 広島県広島市安佐南区毘沙門台1丁目〜4丁目（自治体コード: `34105`）
- **中心座標**: 北緯 `34.462` 度、東経 `132.442` 度
- **初期カメラ位置**: 高度約 `7200m`、北西方向の斜面を見下ろすアングル（`heading: 315°`, `pitch: -35°`）
- **バウンディングボックス（BBox）**: 南西 `(34.460, 132.472)` 〜 北東 `(34.478, 132.490)`
- **周辺メッシュコード**: `51325397`、`51325398`
- **交通施設**: アストラムライン各駅（毘沙門台駅、安東駅、上安駅、高取駅、長楽寺駅等）、広島交通・広電バス等

## データソース構成

- **呉市データ**: `public/data/kure/`
  - `stops.geojson` / `transit-facilities.geojson` / `stations.geojson`: 路線バス停およびJR駅
  - `place-labels.json`: 国土地理院（GSI）公式住所検索APIより取得した町丁目名（113箇所）
  - `bldg/`: PLATEAU 3D Tiles / GeoJSON フォールバック
- **広島市データ**: `public/data/hiroshima/`
  - `transit-facilities.geojson` / `bus-stops.geojson` / `stations.geojson`: アストラムライン駅および周辺バス停
  - `place-labels.json`: 町丁目名（213箇所）
  - `road-network.geojson` / `routing-graph.json` / `building-network-scores.json`
