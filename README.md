# PLATEAU 交通空白地可視化・施策シミュレーション（呉市 宮原地区 / 広島市安佐南区 毘沙門台エリア）

CesiumJS で国土交通省 PLATEAU の 3D 都市モデル（建物 LOD1）および地形を表示し、急傾斜市街地である「広島県呉市（宮原地区）」と「広島市安佐南区（毘沙門台エリア）」を対象に、交通空白地の可視化と新規停留所・モビリティハブ配置の施策シミュレーションを行う Web アプリケーションです。

- **公開 URL（本番環境）**: https://hiroshima-transit.vercel.app/
- **関連プロジェクト（藤沢市北部版）**: https://plateau-transit-poc.vercel.app/

## 主な機能

1. **マルチエリア切替（呉市・広島市）**
   - 画面左上のセレクターから「呉市（宮原地区）」と「広島市安佐南区（毘沙門台エリア）」を即座に切り替えられます。
   - 選択中のエリアに応じてブラウザのタブタイトルも動的に更新されます。

2. **交通アクセス圏の可視化と距離モデル切替**
   - 既定のカバー圏判定基準を **バス停400m／鉄道駅800m** に設定し、PLATEAU の建物用途（`bldg:usage`）属性を用いて対象建物を抽出・色分け表示します。
   - **直線距離モデル**と、実道路網および標高差を考慮した**道路網距離モデル（勾配負荷考慮）**を切り替え可能です。
   - 運動生理学（METs 等）に基づく上り坂の歩行負荷増加や、都市交通研究における急傾斜地の歩行回避傾向を踏まえ、上り・下りや一般・高齢者の歩行プロファイルに応じた換算距離でアクセシビリティを評価します。

3. **仮設バス停・モビリティハブ配置シミュレーション**
   - 地図上の任意の地点をクリックして仮設バス停やモビリティハブを配置できます。
   - バックエンド API（`/api/snap-road`）により、急傾斜地や階段・細街路を含む OpenStreetMap 歩行可能道路ネットワークへ最寄りスナップ（最大許容距離 `60m`）を行い、Web Worker 上の MinHeap Dijkstra 法によって周辺建物の到達スコアとカバー改善効果をリアルタイムに再計算します。

4. **シミュレーション結果のエクスポート**
   - 配置した仮設バス停やモビリティハブ・改善分析結果を GeoJSON 形式でエクスポートできます。

## 対象エリアとパラメータ設定

### 1. 呉市（宮原地区）※デフォルト

- **対象地域**: 広島県呉市宮原1丁目〜8丁目周辺（急傾斜市街地、自治体コード: `34202`）
- **中心座標**: 北緯 `34.2435` 度、東経 `132.5630` 度
- **初期カメラ位置**: 呉港・二河川河口側から呉駅・宮原・和庄・内陸斜面市街地を見通す俯瞰アングル（高度約 `2350m`、`heading: 42°`、`pitch: -23°`）
- **周辺メッシュコード**: `51322485`、`51322486`、`51322475`、`51322476`
- **交通施設**: JR呉線 3駅（呉駅・川原石駅・安芸阿賀駅 ※川原石駅は現況駅舎位置 `[132.54145, 34.24872]` に補正済み）、広電バス・呉市生活バス等の停留所 398箇所（合計 401箇所）
- **勾配負荷パラメータ（急傾斜・階段市街地向け）**:
  - 一般プロファイル: 勾配負荷係数 `4.5`、上り坂距離倍率 `1.55`、下り坂距離倍率 `1.1`
  - 高齢者プロファイル: 勾配負荷係数 `9.0`、上り坂距離倍率 `1.85`、下り坂距離倍率 `1.2`
  - 勾配上限: `0.45`、道路網迂回係数: `1.48`

### 2. 広島市安佐南区（毘沙門台エリア）

- **対象地域**: 広島県広島市安佐南区毘沙門台1丁目〜4丁目周辺（自治体コード: `34105`）
- **中心座標**: 北緯 `34.462` 度、東経 `132.442` 度
- **初期カメラ位置**: 高度約 `7200m`、北西方向の斜面を見下ろすアングル（`heading: 315°`、`pitch: -35°`）
- **バウンディングボックス（BBox）**: 南西 `(34.460, 132.472)` 〜 北東 `(34.478, 132.490)`
- **周辺メッシュコード**: `51325397`、`51325398`
- **交通施設**: アストラムライン各駅（毘沙門台駅、安東駅、上安駅、高取駅、長楽寺駅 等）を含む駅 36箇所、広島交通・広電バス等の停留所 1,364箇所（合計 1,400箇所）
- **勾配負荷パラメータ**:
  - 勾配負荷係数: 一般 `3.5` ／ 高齢者 `7.0`
  - 勾配サンプリング点数: `5`、勾配上限: `0.4`、上り坂距離倍率 `1.25`、下り坂距離倍率 `1.0`

## データソース構成

### 呉市データ（`public/data/kure/`）
- `stations.geojson`（3件）/ `stops.geojson`（398件）/ `transit-facilities.geojson`（401件）: JR駅・路線バス停データ
- `place-labels.json`（113件）: 国土地理院（GSI）住所検索データに基づく町丁目ラベル
- `routing-graph.json`（22,050ノード / 24,040エッジ）: 上平原町・平原町周辺を含む歩行可能道路ネットワークグラフ
- `bldg/`: PLATEAU 建物データ

### 広島市データ（`public/data/hiroshima/`）
- `stations.geojson`（36件）/ `bus-stops.geojson`（1,364件）/ `transit-facilities.geojson`（1,400件）: アストラムライン駅およびバス停データ
- `place-labels.json`（213件）: 町丁目ラベル
- `routing-graph.json`（8,493ノード / 9,501エッジ）: 歩行可能道路ネットワークグラフ
- `snap-roads.json`（49,587ノード / 55,466エッジ）: 長楽寺・高取・伴・毘沙門台・祇園・大町周辺まで網羅した道路スナップ用ネットワーク
- `building-network-scores.json`（9,994棟）: 事前計算済み道路網到達スコア

## ローカル開発・検証手順

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いて動作を確認してください。

npx tsc --noEmit    # TypeScript 型チェック
npm run lint        # ESLint 実行
npm run build       # 本番用ビルド検証
